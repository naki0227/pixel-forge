# 株式会社ピクセル・フォージ（架空）コーポレートサイト

Webデザイン演習 最終課題。架空のインディーゲームスタジオのコーポレートサイト（静的HTML）。

## ページ
| ファイル | 内容 |
|---|---|
| index.html | トップ（メインビジュアル・NEWS・代表メッセージ） |
| company.html | 会社概要（代表メッセージ・会社概要・地図） |
| games.html | 開発タイトル一覧（開発の形・機種で絞り込み） |
| recruit.html | クリエイター採用 |
| contact.html | お問い合わせ（入力 → 確認 → 完了。どこにも送信しない） |

## 直し方
- 本文は `src/*.html`、全ページ共通のヘッダー・フッターは `src/_header.html` / `src/_footer.html`。
- 直したら `python3 tools/build.py` で直下の HTML を作り直す（依存なし、Python 3 だけ）。
- 公開に要るのは直下の `*.html`・`css/`・`js/`・`images/` だけ（Moodle に上げるときもこれだけ）。

## 要件定義との対応
1. ページ構成：トップ＋サブページ4つ
2. ナビゲーション：全ページ共通のヘッダー（スマホはMENUで開閉）
3. レスポンシブ：900px・600px で組み替え、横スクロールなし（1440px・390px で確認）
4. 見出し：各ページ h1 → h2 → h3
5. 画像：課題素材の画像を `images/` に入れる（未）
6. インタラクティブ：タイトルの絞り込み、問い合わせの確認画面、Googleマップの埋め込み
7. 公開：Vercel（予定）
